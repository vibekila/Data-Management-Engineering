## Домашнее задание №7

В рамках работы разработан скрипт переноса данных плетизмографии грызунов из локального Parquet-архива в удаленную систему управления базами данных (СУБД).

### Структура и запуск
* Скрипт расположен по пути: `scripts/write_to_db.py`
* Зависимости для работы с СУБД добавлены в файл `requirements.txt` (`psycopg2-binary`, `python-dotenv`)

### Логика работы
1. Доступы к удаленному серверу изолированы в локальном файле конфигурации окружения `.env`. Сам файл `.env` и исходная локальная база `creds.db` принудительно скрыты от системы контроля версий и занесены в `.gitignore`.
2. Перебор строк датасета переведен на пакетную вставку методом `cursor.executemany()`.
3. Скрипт автоматически сканирует структуру датафрейма (`df.dtypes`) и создает SQL-запросы с корректным приведением типов данных (`DOUBLE PRECISION` / `TEXT`).
