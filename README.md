# Домашнее задание №2

**Суть задания:** Первичная обработка, очистка и подготовка структурированных данных для дальнейшего анализа.

**О работе с датасетом:** В проекте исследуются результаты плетизмографии самцов мышей линии CD1. Датасет содержит 15 признаков, описывающих параметры дыхания.

## Описание датасета
* **Размер скачиваемого файла:** 72 КБ
* **Количество записей:** 1000 строк
* **Количество признаков:** 15 столбцов

## Ссылки
* **Ссылка на датасет:** [dataset_for_DME](https://docs.google.com/spreadsheets/d/1op5pVvniPLiL88I-HxvgWKKqM0AA2PsP/edit)

## Инструкция по запуску

```bash
pip install -r requirements.txt
python data_loader.py
```

После успешного запуска скрипта в консоль выведутся первые 10 строк таблицы.
