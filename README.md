# Домашняя работа №1

Решение домашней работы №1 в рамках курса Инжиниринга управления данными.

**Суть задания:** Первичная обработка, очистка и подготовка структурированных данных для дальнейшего анализа.

**О работе с датасетом:** В проекте исследуются результаты плетизмографии самцов мышей линии CD1. Датасет содержит 15 признаков, описывающих параметры дыхания животных.
