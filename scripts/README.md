# Скрипт сбора данных из открытого API

## Описание работы
Скрипт `read_api.py` осуществляет автоматизированный опрос публичного программного интерфейса международной научной базы данных **GBIF (Global Biodiversity Information Facility)**.

## Технические детали
1. **Объект исследования:** Записи находок представителей отряда Жуков (Coleoptera) в дикой природе.
2. **Источник данных:** Публичный эндпоинт API GBIF (`pygbif.occurrences.search`).
3. **Состав признаков датасета:** Научное название (латынь), семейство, род, страна, географические координаты (широта и долгота), год фиксации.

## Инструкция по работе

### 1. Установка зависимостей
Для установки библиотек, необходимых для работы скрипта сбора данных, выполните команду в корневой директории проекта:
```bash
pip install -r requirements.txt
```

### 2. Запуск скрипта
Для запуска процесса опроса API и вывода первых 10 строк таблицы выполните следующую команду:
```bash
python scripts/read_api.py
```
