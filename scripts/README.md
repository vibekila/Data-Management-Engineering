# Скрипт сбора данных из открытого API

## Описание работы
Скрипт `read_api.py` осуществляет автоматизированный опрос публичного программного интерфейса международной научной базы данных **GBIF (Global Biodiversity Information Facility)**.

## Технические детали
* **Объект исследования:** Записи обнаружения представителей отряда Жуков (Coleoptera) в дикой природе.
* **Источник данных:** Публичный эндпоинт API GBIF (`pygbif.occurrences.search`).
* **Состав признаков датасета:** Научное название (латынь), семейство, род, страна, локация, географические координаты (широта и долгота), год фиксации.
